# 订单、付款与退款对账报告

## 计算口径

- 依据 `rules.md`，订单金额按 `orders.csv` 中的订单统计；付款按付款 ID 去重。同 ID 重复行内容一致，因此 `P202` 只计一次。
- 仅将状态为 `paid` 且订单存在的付款计入有效付款；失败或取消的付款不计入。订单未收金额按 `max(订单金额 - 有效付款, 0)` 计算，退款不增加该指标。
- 仅将状态为 `settled`、能匹配有效付款且退款订单 ID 与付款订单 ID 一致的退款冲减回款。待结算退款不冲减；不能匹配付款的已结算退款列为孤立退款。
- 净回款 = 有效付款 - 已生效退款；汇总数为逐订单金额之和。金额单位为元。

## 异常及记录依据

- **重复付款 ID：`P202`**。`payments.csv` 中针对 `O102` 的两条 `P202` 记录均为 80 元、`paid`；按规则去重后只计一次。
- **孤立付款：`P205`**。`payments.csv` 记录其为 50 元、`paid`，但订单号 `O999` 不在 `orders.csv` 的订单 `O101`–`O106` 中，故不计入回款。
- **未计入的失败/取消付款：`P206`、`P207`**。`payments.csv` 中 `P206`（`O104`，60 元）状态为 `failed`，`P207`（`O106`，90 元）状态为 `cancelled`。
- **未付款订单：`O104`、`O106`**。根据 `orders.csv` 及上述排除的付款，二者有效付款均为 0。
- **部分付款订单：`O105`**。`orders.csv` 订单额 150 元，`payments.csv` 的有效付款 `P204` 为 75 元，未收 75 元。
- **待结算退款：`R303`**。`refunds.csv` 中对应 `P204` / `O105` 的 10 元退款状态为 `pending`，不冲减回款。
- **孤立退款：`R304`**。`refunds.csv` 中该 5 元退款状态为 `settled`、订单号为 `O102`，但付款 ID `P999` 无法匹配到 `payments.csv` 中可计入的付款，因此不生效。
- **已生效退款记录：`R301`、`R302`**。`refunds.csv` 中 `R301`（`P203` / `O103`）30 元及 `R302`（`P201` / `O101`）20 元均为已结算，且与相应有效付款和订单匹配；合计冲减 50 元。

本报告仅依据本目录的 `orders.csv`、`payments.csv`、`refunds.csv` 和 `rules.md`。关键记录 ID 已在逐单结果和异常说明中列出；未使用外部资料。
