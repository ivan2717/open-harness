# 订单、付款与退款对账报告

## 计算口径

依据 `rules.md` 第 1–7 条，按订单唯一记录汇总；付款按 `payment_id` 去重，仅统计状态为 `paid` 且订单存在的付款。退款仅在状态为 `settled`、能匹配已计入付款且退款 `order_id` 与该付款订单一致时冲减净回款。`pending` 退款不冲减。订单未付金额按 `max(订单金额 - 有效付款, 0)` 计算，不因退款增加。

来源文件为 `orders.csv`、`payments.csv`、`refunds.csv` 和 `rules.md`；未使用外部资料，原始材料未修改。

## 汇总结果

| 指标 | 金额（元） |
|---|---:|
| 订单总额 | 700 |
| 匹配且计入的付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付金额 | 225 |

复核计算：`orders.csv` 的 O101–O106 金额合计为 700；有效付款为 P201 120、P202 80、P203 200、P204 75，合计 475；有效退款为 R302 20、R301 30，合计 50；净回款 `475 - 50 = 425`。未付金额为 O104 的 60、O105 的 75、O106 的 90，合计 225。

## 异常记录

- **重复付款：P202**（`payments.csv` 两行，均为 O102、80 元、`paid`）。依 `rules.md` 第 2 条只计一次；O102 有效付款为 80，而非 160。
- **孤立付款：P205**（`payments.csv`：O999、50 元、`paid`）。O999 不在 `orders.csv`，不计入回款。
- **失败或取消付款：P206、P207**（`payments.csv`：P206/O104 为 `failed`，P207/O106 为 `cancelled`）。均排除，因此 O104 与 O106 无有效付款。
- **孤立退款：R304**（`refunds.csv`：P999/O102、5 元、`settled`）。付款 P999 无法匹配到已计入付款；虽然退款列有 O102，也不冲减 O102。
- **未结算退款：R303**（`refunds.csv`：P204/O105、10 元、`pending`）。不冲减 O105。
- **未付款订单：O104、O106**；**部分付款订单：O105**（有效付款 P204 为 75 元，订单金额 150 元）。

异常分类与金额口径依据 `rules.md` 第 2–7 条；本报告列出的 ID 均对应上述来源文件中的实际记录。
