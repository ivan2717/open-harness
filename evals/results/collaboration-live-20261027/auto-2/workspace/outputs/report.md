# 订单、付款与退款对账报告

## 计算口径

依据 `rules.md`：订单总额按 `orders.csv` 中的唯一订单求和；付款先按 `payment_id` 去重，仅将状态为 `paid` 且订单存在的付款计入；退款仅在状态为 `settled`、其付款已计入且退款行的订单 ID 与付款订单一致时冲减回款。未付款金额按 `max(订单金额－有效付款, 0)` 计算，不因退款增加。所有金额单位为元。

## 汇总结论

| 指标 | 金额（元） |
| --- | ---: |
| 订单总额 | 700 |
| 匹配有效付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付款金额 | 225 |

核对关系：`475 - 50 = 425`；订单金额合计为 `120 + 80 + 200 + 60 + 150 + 90 = 700`。有效付款包括 P201、P202、P203、P204；生效退款为 R302（冲减 O101 的 20 元）和 R301（冲减 O103 的 30 元）。

## 异常与未纳入记录

- **重复付款：P202**（`payments.csv`）：O102 的相同付款行出现两次；按规则仅计一次，计入金额 80 元。
- **孤立付款：P205**（`payments.csv`）：状态为 `paid`，但关联订单 O999 不在 `orders.csv`，不计入有效付款。
- **失败或取消付款：P206、P207**（`payments.csv`）：P206 状态为 `failed`，P207 状态为 `cancelled`，均不计入。
- **孤立退款：R304**（`refunds.csv`）：虽为 `settled` 且标注 O102，但关联付款 P999 无法匹配到已计入付款，因此不冲减回款。
- **待结算退款：R303**（`refunds.csv`）：状态为 `pending`，金额 10 元，不冲减回款。
- **未付款订单：O104、O106**（`orders.csv`）：有效付款为 0。
- **部分付款订单：O105**（`orders.csv`、`payments.csv`）：订单金额 150 元，仅有效付款 75 元。

订单来源记录为 `orders.csv` 的 O101–O106；付款依据为 `payments.csv` 中的 P201–P207（包括重复的 P202）；退款依据为 `refunds.csv` 中的 R301–R304。以上结论仅依据本目录所给材料及 `rules.md`，未使用外部资料。
