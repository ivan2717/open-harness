# 订单、付款与退款对账报告

## 计算口径

依据 `rules.md`，以 `orders.csv` 中唯一订单为统计范围，金额单位为元。付款按 `payment_id` 去重；仅 `status=paid` 且订单存在的付款计入。退款仅在状态为 `settled`、对应付款已计入且退款 `order_id` 与该付款所属订单一致时冲减净回款。`pending` 退款不冲减。退款前未付金额按 `max(订单金额－有效付款, 0)` 计算，退款不改变该指标。订单净回款为有效付款减已生效退款。

## 汇总

| 指标 | 金额（元） |
|---|---:|
| 订单总额 | 700 |
| 匹配并计入的付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付金额 | 225 |

核算依据：`orders.csv` 中 O101–O106 金额合计 700；`payments.csv` 中计入 P201（O101，120）、P202（O102，80，仅计一次）、P203（O103，200）、P204（O105，75），合计 475；`refunds.csv` 中计入 R302（P201/O101，20）和 R301（P203/O103，30），合计 50。因此净回款为 475－50＝425。退款前未付为 O104 的 60、O105 的 75、O106 的 90，合计 225。

## 异常及处理

- **重复付款：** `payments.csv` 中 P202（O102，80，paid）有两条内容相同的记录，按规则只计一次；`duplicate_payment_ids` 中只列一次 P202。
- **孤立付款：** P205（O999，50，paid）在 `payments.csv` 中有记录，但 `orders.csv` 没有订单 O999，因此不计入回款。
- **未计入付款：** P206（O104，60，failed）和 P207（O106，90，cancelled）依 `payments.csv` 状态排除；因此 O104、O106 的有效付款为零，列为未付款订单。
- **部分付款：** P204（O105，75，paid）计入；相对 `orders.csv` 中 O105 的 150，仍未付 75，故 O105 列为部分付款订单。
- **未生效退款：** R303（P204/O105，10，pending）来自 `refunds.csv`，只列为待结算，不冲减回款。
- **孤立退款：** R304（P999/O102，5，settled）来自 `refunds.csv`，但付款 P999 无可匹配的已计入付款记录，因此不冲减回款，并列为孤立退款。
- **已生效退款：** R301（P203/O103，30，settled）及 R302（P201/O101，20，settled）均匹配已计入付款且订单一致，分别冲减 O103、O101。

以上核对仅依据 `orders.csv`、`payments.csv`、`refunds.csv` 和 `rules.md`；未修改原始材料。
