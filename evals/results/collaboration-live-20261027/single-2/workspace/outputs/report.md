# 订单、付款与退款对账报告

## 计算口径

依据 `rules.md`，订单总额按 `orders.csv` 中的唯一订单统计。付款先按 `payment_id` 去重（相同 ID、内容一致的重复记录只计一次）；仅状态为 `paid` 且订单 ID 存在的付款计入。退款仅在状态为 `settled`、对应付款已计入且退款行的订单 ID 与付款订单一致时冲减回款。`pending` 退款不冲减；无法匹配已计入付款的已结算退款作为孤立退款。未付金额按 `max(订单金额 - 有效付款, 0)` 计算，不因退款增加。

## 汇总结论

| 指标 | 金额（元） |
|---|---:|
| 订单总额 | 700 |
| 匹配并计入的付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付金额 | 225 |

复核：`orders.csv` 的 6 笔订单金额合计为 700；有效付款为 `P201` 120 + `P202` 80 + `P203` 200 + `P204` 75 = 475；生效退款为 `R302` 20 + `R301` 30 = 50；净回款 `475 - 50 = 425`。逐单退款前未付金额为 `O104` 60、`O105` 75、`O106` 90，合计 225。

## 逐单结果与异常依据

- `O101`（订单 120）：计入付款 `P201` 120；生效退款 `R302` 20；净回款 100，退款前未付 0。
- `O102`（订单 80）：计入付款 `P202` 80（`payments.csv` 中该 ID 出现两行，按规则去重）；无生效退款，净回款 80，退款前未付 0。
- `O103`（订单 200）：计入付款 `P203` 200；生效退款 `R301` 30；净回款 170，退款前未付 0。
- `O104`（订单 60）：付款 `P206` 状态为 `failed`，不计入；有效付款为 0，未付款 60，净回款 0。
- `O105`（订单 150）：计入付款 `P204` 75；退款 `R303` 状态为 `pending`，不冲减；部分付款 75，退款前未付 75，净回款 75。
- `O106`（订单 90）：付款 `P207` 状态为 `cancelled`，不计入；有效付款为 0，未付款 90，净回款 0。

异常清单及来源记录：

- 重复付款 ID：`P202`（`payments.csv`，同为 `O102`、80、`paid` 的重复行；仅计一次）。
- 孤立付款 ID：`P205`（`payments.csv`，`paid` 50，但订单 `O999` 不在 `orders.csv`）。
- 孤立退款 ID：`R304`（`refunds.csv`，`settled` 5，指向不存在的付款 `P999`；不计入 `O102`）。
- 未付款订单：`O104`（排除 `P206`，`failed`）、`O106`（排除 `P207`，`cancelled`）。
- 部分付款订单：`O105`（订单 150、有效付款 `P204` 75）。
- 排除付款 ID：`P206`（`failed`）、`P207`（`cancelled`）；均来自 `payments.csv`。
- 未结算退款 ID：`R303`（`refunds.csv`，`pending`，不冲减）。

来源文件：`orders.csv`、`payments.csv`、`refunds.csv`、`rules.md`。本报告仅按这些材料对账；未引入外部资料。
