# 订单、付款与退款对账报告

## 对账口径

依据 `rules.md`：订单金额按 `orders.csv` 中唯一订单汇总；付款按 `payment_id` 去重，只纳入状态为 `paid` 且订单存在的记录。退款仅当状态为 `settled`、引用的付款已计入，且退款与付款的订单 ID 一致时才冲减净回款。未结算退款不冲减；无匹配有效付款的已结算退款列为孤立退款。未退款前未付金额按 `max(订单金额－有效付款, 0)` 计算。

## 汇总结论

| 指标 | 金额（元） |
|---|---:|
| 订单总额 | 700 |
| 匹配有效付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付金额 | 225 |

计算复核：`orders.csv` 的 6 笔订单合计为 120 + 80 + 200 + 60 + 150 + 90 = 700；计入的付款为 P201（120）+ P202（80）+ P203（200）+ P204（75）= 475；生效退款为 R302（20）+ R301（30）= 50；因此净回款为 475 − 50 = 425。退款前未付金额为 O104（60）+ O105（75）+ O106（90）= 225。
