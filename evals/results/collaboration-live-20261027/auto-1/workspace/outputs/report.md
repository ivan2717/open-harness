# 订单、付款与退款对账报告

## 计算口径

依据 `rules.md`：订单总额按 `orders.csv` 中每个订单统计；付款按 `payment_id` 去重，仅将状态为 `paid` 且订单存在的付款计入；退款仅在状态为 `settled`、所关联付款已计入且退款订单与付款订单一致时冲减净回款。未结算退款不冲减。未付金额按“订单金额－有效付款”计算并以 0 为下限，退款不影响未付金额。所有金额单位为元。

## 汇总结论

| 指标 | 金额 |
|---|---:|
| 订单总额 | 700 |
| 匹配有效付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付金额 | 225 |

核算关系：有效付款为 O101 的 120（P201）、O102 的 80（P202）、O103 的 200（P203）及 O105 的 75（P204），合计 475。生效退款为 R302 的 20（P201/O101）和 R301 的 30（P203/O103），合计 50；净回款为 475－50＝425。订单总额 700 减有效付款 475，退款前未付金额为 225。

## 异常与未计入记录

- **重复付款 ID：P202。** `payments.csv` 中 P202（O102，80，paid）出现两行且内容一致，按规则仅计一次。
- **孤立付款：P205。** `payments.csv` 中 P205 为 O999 的已付款 50，但 `orders.csv` 没有 O999，因此不计入匹配付款。
- **孤立退款：R304。** `refunds.csv` 中 R304 为 O102 的已结算退款 5，但其付款 ID P999 无法匹配到已计入付款，故不冲减回款。
- **未结算退款：R303。** `refunds.csv` 中 R303（P204/O105，10，pending）尚未结算，不冲减回款。
- **排除的付款：P206、P207。** `payments.csv` 中 P206（O104，60，failed）及 P207（O106，90，cancelled）状态不符合计入条件，未计为有效付款。
- **未付款订单：O104、O106。** 均无有效付款；**部分付款订单：O105。** 有效付款 75，小于订单金额 150。

本报告和结构化结果仅依据 `orders.csv`、`payments.csv`、`refunds.csv` 与 `rules.md`；未使用外部资料，原始材料未修改。
