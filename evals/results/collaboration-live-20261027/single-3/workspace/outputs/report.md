# 订单、付款与退款对账报告

## 计算口径

- 依据 `rules.md`，金额单位为元；订单总额按 `orders.csv` 中每个唯一订单统计。
- `payments.csv` 先按付款 ID 去重。同 ID 重复行内容一致，只计一次；仅 `paid` 且订单存在的付款计入有效付款。失败、取消以及订单不存在的付款不计入。
- 退款仅在状态为 `settled`、对应付款已计入且退款订单 ID 与该付款的订单 ID 一致时冲减回款。`pending` 不冲减；已结算但无法匹配已计入付款的退款列为孤立退款。
- 每单未付金额按 `max(订单金额 - 有效付款, 0)` 计算，不因退款增加。净回款为有效付款减已生效退款。

## 汇总结论

| 指标 | 金额（元） |
|---|---:|
| 订单总额 | 700 |
| 匹配有效付款 | 475 |
| 已生效退款 | 50 |
| 净回款 | 425 |
| 退款前未付金额 | 225 |

核算关系：`120 + 80 + 200 + 75 = 475`（有效付款）；`20 + 30 = 50`（生效退款）；`475 - 50 = 425`（净回款）。六笔订单金额合计 `120 + 80 + 200 + 60 + 150 + 90 = 700`；未付金额为 `60 + 75 + 90 = 225`。

## 异常与待处理记录

- **重复付款 ID：** `payments.csv` 中 `P202` 对应 O102 的 80 元付款出现两行（两行内容一致），按规则仅计一次。
- **孤立付款：** `payments.csv` 的 `P205` 为 O999 的 50 元已付款记录，但 `orders.csv` 不存在订单 O999，因此不计入。
- **孤立退款：** `refunds.csv` 的 `R304` 为 O102 的 5 元已结算退款，关联付款 `P999`；该付款不在已计入的付款中，故不冲减回款。依规则，孤立退款仍不计入有效退款。
- **未付款订单：** O104、O106（依据 `orders.csv` 的订单金额，以及 `payments.csv` 中没有匹配的有效付款）。
- **部分付款订单：** O105，订单额 150 元，仅计入 `P204` 的 75 元付款，尚欠 75 元。
- **排除的付款：** `P206`（status=`failed`，60 元）与 `P207`（status=`cancelled`，90 元），均不计入。
- **未结算退款：** `refunds.csv` 的 `R303`（关联 `P204`、O105、10 元，status=`pending`）暂不冲减净回款。

汇总及逐单机器可核对数据见 [`reconciliation.json`](reconciliation.json)。本报告仅依据 `orders.csv`、`payments.csv`、`refunds.csv` 与 `rules.md`；未使用外部资料。
