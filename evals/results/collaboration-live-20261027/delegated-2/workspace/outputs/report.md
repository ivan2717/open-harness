# 订单、付款与退款对账报告

## 计算口径

依据 `rules.md`：订单总额按 `orders.csv` 中的唯一订单计算；付款按 `payment_id` 去重，仅计入状态为 `paid` 且能匹配原订单的付款。退款只有在状态为 `settled`、对应到已计入付款、且退款订单与付款订单一致时才冲减净回款。每单净回款 = 有效付款 − 已生效退款；退款前未付金额 = max(订单金额 − 有效付款, 0)，退款不增加该指标。金额单位为元。

## 汇总

| 指标 | 金额（元） | 计算依据 |
|---|---:|---|
| 订单总额 | 700 | `orders.csv`：O101–O106，120+80+200+60+150+90 |
| 匹配有效付款 | 475 | `payments.csv`：P201=120、P202=80（重复行仅计一次）、P203=200、P204=75 |
| 已生效退款 | 50 | `refunds.csv`：R302=20（对应P201/O101）、R301=30（对应P203/O103） |
| 净回款 | 425 | 475−50；亦等于逐单净回款之和 |
| 退款前未付金额 | 225 | O104=60、O105=75、O106=90，合计225 |

## 异常与处理

- **重复付款 ID：P202。** `payments.csv` 中 P202 对应 O102 的 80 元 `paid` 记录出现两次且内容一致；按规则只计一次，因此 O102 有效付款为80元。
- **孤立付款 ID：P205。** `payments.csv` 中 P205 为 O999 的 50 元 `paid` 记录；`orders.csv` 没有 O999，因此不计入回款。
- **孤立退款 ID：R304。** `refunds.csv` 中 R304 为 O102 的 5 元 `settled` 退款，但引用付款 P999，无法匹配已计入付款，故不冲减回款。
- **未付款订单：O104、O106。** O104 关联的 P206 状态为 `failed`，O106 关联的 P207 状态为 `cancelled`；按规则不计入有效付款。
- **部分付款订单：O105。** 订单金额150元，仅有 P204 的75元有效付款，尚欠75元。
- **排除付款：P206、P207。** 分别为 `failed`、`cancelled` 状态，不计入有效付款。
- **未结算退款：R303。** 对应 P204/O105 的10元退款状态为 `pending`，不冲减净回款。

本报告仅依据本目录的 `orders.csv`、`payments.csv`、`refunds.csv` 和 `rules.md`；上文列明的记录 ID 为可追溯依据。原始材料未修改。
