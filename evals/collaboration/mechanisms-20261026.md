## 验收证据

- **实际并发与结果收齐**：两个子任务的模型请求被同时阻塞时，父任务仍保持运行；释放后两条结果持久化送达，父任务下一次请求包含两者结果，子任务完成。
- **上下文交接与回查**：子任务收到父任务公开背景；长中文消息可以按字符偏移回查完整尾部，响应没有返回私有推理字段。子任务不能继续派生其他 agent。
- **工作区与 MCP 继承**：未收窄权限的子任务可以使用父任务工作区写入工具并发现已配置 MCP；子任务新审批在父任务展示来源并由父任务批准，无关根会话无法批准。实际执行使用模拟 MCP 服务。
- **可复用授权边界**：父任务一次性批准不能被子任务继承；成功建立的会话批准可由同组子任务复用；独立 MCP 客户端仍按成员隔离。其他根会话不能复用。
- **拒绝、撤回及失败**：拒绝、取消和失效审批不会启动 MCP 服务；撤回根任务授权使子任务旧客户端和旧 epoch 失效；失败的子任务目标选择不会泄漏可复用授权；停止单个子任务不会误撤销父授权。
- **停止与重启**：停止父任务后父子状态全部取消；未消费的子结果保留。重建服务后关系和结果仍在，未自动发起新模型请求。用户明确停止的子任务不能由 agent 自动重启。
- **共享工作区与命令**：文件范围租约拒绝冲突；父会话可以审批和停止子命令；仅显式根会话授权可用于命令复用；权限和记录不串到其他根任务。
- **撤销修改**：子任务撤销日志重启后可用；撤销等待同组活动结束，不覆盖其他活动任务或后续修改，失败时正确释放租约。
- **桌面/浏览器授权控制**：模拟桌面操作记录为 `start/end/start/end`，验证同组输入串行；Chrome 范围按标签页及 origin 校验，不能用批准的一页或域名扩展到其他目标。
- **执行边界**：可执行超过 12 个工具循环；显式步数限制暂停后可续行；并发数量上限拒绝多余子任务。

## 未覆盖与解释范围

这些测试通过真实 API 服务、协议适配器、执行循环和持久化路径，使用脚本化模型与本地模拟 MCP 控制时序。它们证明指定场景的机制断言成立，**不证明真实模型会合理分工、会使用证据或会生成正确业务答案**。

本轮未验证桌面安装包点击体验、真实 Chrome 扩展/原生电脑交互、Windows 原生执行、外部 MCP 服务稳定性、真实模型并发限流、长期压缩后的业务正确性，也没有测量 API 费用。停止测试覆盖已发出模型请求的取消与重启不重放，并不等同于对所有外部副作用的事务回滚保证。

真实订单对账评分与主子 agent 的时间/用量对照应另行记录，并与这 54 项机制测试分开报告。
