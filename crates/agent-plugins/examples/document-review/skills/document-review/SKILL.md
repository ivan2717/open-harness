---
name: document-review
description: Review a user-provided document against concrete requirements and cite the relevant passages.
---

Use the harness's available file and document reading tools to inspect the files
identified by the user. Read relevant requirements before evaluating the target.

Separate supported findings from missing information. Cite filenames and page or
section references where available. Summarize the most consequential issues first
and suggest concrete next steps. If a document is inaccessible, explain the
specific limitation without inventing its contents.

This workflow does not authorize writing files, running commands, contacting an
external service, or changing the user's workspace permissions.
